# Job Descriptions for the SmartHire Engineering Experiment (FINAL, Phase 1)

5 JDs x 10 requirements. Requirements are canonical skill names as matched by the graph.
Grounding notes per JD are in jds.json and in METHODS_PHASE1.md. JDs were NOT fitted to
individual resumes; requirement choice is by frequency within the assigned group plus
standard posting practice (see grounding notes).

## Mechanical Engineer (n = 45 assigned resumes)

Mechanical Engineer to design, analyse and improve mechanical components, systems and manufacturing processes.

Responsibilities:
- Prepare 2D/3D designs and engineering drawings for components and assemblies.
- Validate designs with simulation and analysis tools.
- Support CNC manufacturing and shop-floor production.
- Drive process improvement, quality and cost reduction on the production line.

Requirements:
1. AutoCAD
2. SolidWorks
3. ANSYS
4. CNC
5. GD&T
6. Lean Manufacturing
7. Six Sigma
8. Manufacturing Processes
9. Welding
10. Process Improvement

Grounding: Requirements ranked by frequency in the 45 assigned resumes: AutoCAD 21, Process Improvement 13, Lean Manufacturing 12, SolidWorks 12, Six Sigma 11, CNC 10, Welding 10, ANSYS 10, Manufacturing Processes 7, GD&T 6.

## Electrical Engineer (n = 19 assigned resumes)

Electrical Engineer to design, commission and maintain control, automation and power systems.

Responsibilities:
- Design and commission PLC-based control and automation systems.
- Work on power distribution, instrumentation and electrical design.
- Use simulation tools for system modelling and validation.
- Support installation, testing and maintenance of electrical systems.

Requirements:
1. PLC
2. SCADA
3. Control Systems
4. Automation
5. Instrumentation
6. MATLAB
7. Power Systems
8. Power Distribution
9. Embedded Systems
10. Electrical Design

Grounding: Requirements ranked by frequency in the 19 assigned resumes: Automation 8, Control Systems 7, PLC 6, MATLAB 6, Instrumentation 5, Power Distribution 3, Power Systems 3, SCADA 2, Electrical Design 2, Embedded Systems 2.

## Civil Engineer (Site / Structural) (n = 6 assigned resumes)

Civil Engineer to execute and supervise building construction works, from structural design support to site measurement and billing.

Responsibilities:
- Supervise site execution and coordinate contractors and drawings.
- Prepare quantity estimates, measurements and bills.
- Carry out surveying and setting-out work.
- Check structural details, reinforcement and concrete works.

Requirements:
1. STAAD
2. ETABS
3. Structural Analysis
4. Structural Design
5. Quantity Estimation
6. Surveying
7. Reinforced Concrete
8. Building Construction
9. Site Execution
10. Concrete

Grounding: Small group (n=6) with varied site-focused resumes: Concrete 3, Estimation 1, Surveying 1, Structural Analysis 1, Reinforced Concrete 1; STAAD/ETABS 0. JD is a standard site/structural posting, NOT fitted to the resumes -- several resumes are expected to score low, which is legitimate negative signal. Per-JD metrics for Civil are descriptive only.

## Software Developer (n = 16 assigned resumes)

Software Developer to build and maintain web applications and backend services in an agile team.

Responsibilities:
- Develop features across the stack and write tested, reviewed code.
- Design and consume REST APIs and work with relational databases.
- Use version control and cloud deployment in daily work.

Requirements:
1. Python
2. Java
3. JavaScript
4. SQL
5. Git
6. Docker
7. REST
8. AWS
9. HTML
10. CSS

Grounding: Requirements ranked by frequency in the 16 assigned resumes: JavaScript 7, Python 5, SQL 5, REST API 5, Java 4, HTML 3, CSS 3, Git 2, AWS 1, Docker 0. HTML/CSS are stored as displayed and canonicalised to the graph nodes HTML5/CSS3 by the matcher alias list. Uses the ORIGINAL v3 tech graph only -- no new software nodes were added.

## Engineering Technician (Maintenance / Field Service) (n = 32 assigned resumes)

Engineering Technician to install, maintain, troubleshoot and repair equipment in the field and on site.

Responsibilities:
- Carry out preventive and corrective maintenance on equipment.
- Diagnose faults, read schematics and complete repairs.
- Install and commission equipment and document the work.
- Follow safety procedures and maintain accurate service records.

Requirements:
1. Troubleshooting
2. Equipment Repair
3. Installation
4. Schematics
5. Preventive Maintenance
6. Calibration
7. Diagnostics
8. Equipment Maintenance
9. Hand Tools
10. Safety Compliance

Grounding: Requirements ranked by frequency in the 32 assigned resumes: Troubleshooting 22, Repair 19, Installation 17, Schematics 11, Preventive Maintenance 7, Diagnostic 6, Calibration 6, Equipment Maintenance 5, Hand Tools 5, Safety Compliance 1. Safety Compliance is included despite low frequency because it is a standard requirement of technician postings.
